      Новый агент

      Cursor-агента Bus Cursor поднимает через Cursor CLI (agent -p): роль и входящие уходят ему в промпт. Вброса посреди хода (btw) нет, расход - оценка, запреты «Доступа» - правилом в промпте, а не жёстко.

      Модель, effort и fast - для сессий Claude Code. В чате Cursor модель выбирается в самом Cursor, промпт оркестратора приходит хуком.

      Доступ

      Доступ этой роли задан руками - белым списком tools. Галочки с ним не дружат: переведи роль на галочки или правь строку в файле.

      Переписать с ИИ

      ИИ правит описание и роль прямо в форме. На диск ничего не уходит, пока не нажмёшь «Сохранить».

      Общий промпт всех оркестраторов - правится в шестерёнке

      Приложение
      
      
      Bus Cursor отдельным окном Chrome или Edge, без вкладок; закроешь окно - сервер погаснет сам. Windows - ярлык на рабочем столе, macOS - Bus Cursor в «Программах» и Launchpad, Linux - в меню приложений и на рабочем столе.
      
    
      
    
      Настройки действуют только в этом проекте и переопределяют значения по умолчанию. Поля с пометкой «все проекты» - общие для всей шины.
